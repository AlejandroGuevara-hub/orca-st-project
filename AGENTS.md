# AGENTS.md

## Project

`orca-st-project` — repositorio nuevo, actualmente sin código fuente. Este archivo describe las convenciones para agentes que trabajen aquí.

## Status

- Repositorio recién inicializado (sin stack, build ni tests definidos aún).
- Actualiza esta sección cuando se agregue código, dependencias o tooling.

## Conventions

- No hay convenciones de código establecidas todavía.
- Al introducir un stack, documenta aquí los comandos de instalación, build, lint, typecheck y test.
- El contexto por temática para agentes vive en `docs/agents-context/`. Lee el documento del área antes de trabajar y mantenlo actualizado.

## Working agreements

- Ejecuta lint/typecheck/tests antes de dar una tarea por terminada, una vez existan.
- No hagas commit, push ni abras PRs salvo que se solicite explícitamente.
- Mantén este archivo sincronizado con la estructura real del proyecto.
